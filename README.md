# Sales-Performance-Dashboard-Excel-Power-BI
**Project Overview:** The dashboard helps businesses monitor Revenue growth, Profit trends, Regional sales performance, Top-performing, products, Customer and order insights, Profit margin analysis.

**Tools & Technologies:** Power BI, Microsoft Excel, Power Query, DAX (Data Analysis Expressions).

**Dataset Information**
  Processed 5,000+ sales records,
  Missing values,
  Duplicate records,
  Data inconsistencies,
  Created a clean and analysis-ready dataset.

**Business Insights**
  1. Identified Top 3 products contributing nearly 35% of total revenue.
  2. Analyzed high-performing regions and customer segments.
  3. Enabled data-driven decision-making through KPI tracking.
  4. Improved sales visibility with interactive reporting.
